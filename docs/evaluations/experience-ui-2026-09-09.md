# 体験UIのコピー削減

2026-09-09。利用者が一話をクリアし、共同で解く体験は好評だった一方、作者の説明文が多いと指摘したため調整した。

## 変更

- 飾りの見出し、絵の説明、開始前の紹介、クリア後の余韻を指示する文章を削除。
- しずくの台詞、謎の条件、操作と選択状態は維持。操作方法、通信/保存、生成元、履歴を開閉欄へ。
- 相談の外部送信・従量課金の有無は短く常時表示。正常Mockは警告を出さず、実際の利用不可や制限の通知を残す。
- 正常な音声待機の長文を非表示。処理中、失敗、自動再生拒否は短い案内と詳細で示す。
- ブラウザー確認で、自動再生拒否後に片付けた音声の遅延errorが回復案内を上書きする不具合を再現。現在の音声だけが状態を更新できるよう修正。

## 実測

- Frontend: TypeScript / ESLint / Vitest 160件 / Build 成功。npm auditは0件。既存の大きなJS bundle警告は残る。
- Backend: Ruff / pytest 164件 / pip check 成功。
- 最初の全ブラウザー検査は22成功・1失敗。失敗は上記の自動再生経路で、修正後に体験7件すべて再実行して成功。通常画面を含む最終全体検査はPRのCI結果を参照。
- 体験の完走、誤答の配置維持、初期化確認、通常対話との往復と下書き/履歴/同一canvas維持、320/390px幅、音声不可時の文字操作、開閉欄のキーボード操作、外部APIの費用/送信範囲表示、自動再生拒否から明示再生での回復を検査。
- ローカルEdgeで実VRMの開始画面と盤面を目視。手紙の調査、台詞、VOICEVOXの生成/再生状態、通信詳細の開閉を確認。

## 境界

この調整では自由相談の実APIを再実行していない。API表示と失敗のブラウザー検査は隔離したMockサーバーとテスト応答を利用し、課金なし。
途中でローカルBackendのプロセス停止を観測し起動し直した。原因は特定しておらず、UI変更が原因とは断定しない。
通常対話のUI、謎の内容、相談APIの選択方針、保存の仕様は変更していない。利用者による修正後の見やすさの評価は未実施。
