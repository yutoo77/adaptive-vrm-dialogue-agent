## VRM内部メタデータ

VRoid Studioでの書き出し時に、公式条件に合わせて次を設定した。

- `avatarPermission`: `everyone`
- `commercialUsage`: `corporation`
- `allowRedistribution`: `true`
- `modification`: `allowModificationRedistribution`
- `creditNotation`: `unnecessary`
- 暴力・性的表現：許可
- 宗教・政治、反社会・憎悪表現：不許可
- `otherLicenseUrl`: 公式利用条件URL

## 実装上の判断

AvatarSample_Aは、Phase 1のローカル表示と制御確認には使いやすい。一方、無改変の公式サンプルを最終ポートフォリオの看板キャラクターにすると独自性が弱い。Phase 1の安定化後に、青と白を基調とした自作・改変モデルへ置き換える余地を残す。

2026-08-20に公式条件を再確認し、サンプルモデルを撮影した画像・動画への利用が例示され、クレジット不要であることを確認した。公開Screenshotでは出典を自主表示する。

公開デモ、配布、デモ動画の公開前には、公式利用条件の更新日と公開方法を再確認する。特にWeb公開では、VRM本体が意図せず配布物へ含まれない構成を維持する。
